# ADR 0003 — Голосове введення: звук не зберігається

## Контекст
Власник хоче, щоб людина могла говорити голосом. Звук розпізнає Speech-to-Text у регіоні ЄС.

## Рішення
Звук не зберігається — рішення власника. Щоб це трималося:
- окремий сервіс приймає звук, розпізнає його і стирає файл одразу після розпізнавання;
- щоночі завдання перевіряє, що в Cloud Storage не лишилося жодного звукового файла, і пише звіт власникові;
- журнал кожного видалення зберігається рік.

## Наслідки
- Окремий сервіс, нічне завдання і журнал видалень.

## Звірка з цілями
- служить: G1
- вибір між варіантами розв'язав: рішення власника про звук
- не-цілі й обмеження: C1 — Cloud Run у Європі.
