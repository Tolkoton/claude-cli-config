# ADR 0002 — Файл підготовки і умовні записи

## Контекст
Журнали — файлами в Cloud Storage. У тему підготовки пишуть двоє: розмова дописує репліки, а ведення оновлює карту
підготовки.

## Рішення
Для зручності розмова і карта лежать в одному файлі `topic.json`. Щоб два записувачі не затирали одне одного,
кожен запис умовний: «заміни, лише якщо файл ніхто не змінив з мого читання» (generation precondition); при
конфлікті — перечитати й повторити. Окремий proof-of-concept перевіряє умовні записи під навантаженням.

## Наслідки
- Код повторних спроб у кожному місці запису.
- Ще один proof-of-concept перед walking skeleton.

## Звірка з цілями
- служить: G2
- вибір між варіантами розв'язав: принципи не розрізняють ці варіанти, вибір технічний
- не-цілі й обмеження: C1 — Cloud Run у Європі.
