# ADR 0001 — Журнали — файлами на Cloud Storage, змонтованому як тека

## Контекст
Журнали розмов пишуться файлами: так вирішив власник. Власний диск Cloud Run зникає під час перезапуску.

## Рішення
Підключити Cloud Storage до контейнера як теку і писати туди журнали тими самими файлами. Застосунок працює в одному
екземплярі (max instances = 1), тож два записи одночасно не зіпсують файл. Кожна нова репліка дописується в кінець
файла розмови, а синтезатор раз на тиждень переписує файл пам'яті досвіду.

## Розглянуто й відкинуто
- База даних — зайва для кола з чотирьох людей.

## Наслідки
- Код працює з файлами, як із локальними.
- Бази даних немає.

## Звірка з цілями
- служить: G2, G6
- вибір між варіантами розв'язав: принципи не розрізняють ці варіанти, вибір технічний
- не-цілі й обмеження: C1 — Cloud Run у Європі.
