# Proof-of-concept 101 — модель веде розмову за карткою типу тижня

## Що перевіряємо
Чи модель у ЄС за один виклик на репліку і веде розмову за карткою, і оновлює карту підготовки.

## Пороги «пройшло»
| Що міряємо | Поріг |
|---|---|
| Валідна структурована відповідь | ≥ 57 з 60 реплік |
| Рівно одне питання людині | ≥ 54 з 60 |
| Перший символ відповіді (p90) | ≤ 3 с |
| Уся відповідь (p90) | ≤ 20 с |
| Ціна розмови на 60 реплік | ≤ 2,25 USD |

Розмір знань, на якому PoC пройде ці пороги, стає бюджетом розміру: нова версія знань, більша за нього, не проходить
перевірку.

## Звірка з цілями
- служить: G1, G3
- вибір між варіантами розв'язав: принципи не розрізняють ці варіанти, вибір технічний
