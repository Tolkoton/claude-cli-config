# 088 — Fresh-install E2E: двигун на новому порожньому проєкті

Залежить від: —
Аудит потрібен: ні

## Що зробити
Перевірити, що двигун працює не лише сам на собі.
- У тимчасовій теці створити новий порожній Python-проєкт і встановити двигун через engine.py install.
- Провести через увесь pipeline маленьку фічу (наприклад, CLI-утиліту для обліку задач): business analyst з готовим документом цілей у цій задачі (власника не чекати), architect, slices, tester (якщо вже збудований), overseer, simplifier, release у цьому тимчасовому репозиторії.
- Кожна вада, знайдена дорогою, — окрема задача на board.
- Нічого з тимчасового проєкту не переносити в репозиторій двигуна, крім знайдених вад як задач.

Документ цілей для цієї проби: «Мета — проста CLI-утиліта для обліку особистих задач: додати, позначити виконаною, показати список. Принципи — простота, тести на все. Поки що не робимо — синхронізацію, веб-інтерфейс. Готово — коли три команди працюють і покриті тестами.»

## Готово, коли
Фіча пройшла весь pipeline або чесно описано, де і чому зупинилась; вади — на board.
