## Що сталося
Жива перевірка 044 (Claude Code 2.1.289) відтворила ваду задачі 705 і знайшла причину. Підагент, який перед відповіддю викликав хоч один інструмент, віддає відповідь не текстом, а викликом інструмента SubagentHandback(message=…). У конверті SubagentStop тоді поля last_assistant_message немає взагалі (перевірено окремою пробою: hook, що записує конверт; підагент general-purpose прочитав файл і відповів JSON-ом — у конверті поля немає, а JSON лежить у файлі agent_transcript_path як вхід виклику SubagentHandback). overseer_verdict.py record читає лише last_assistant_message (рядок 602), тому пише INVALID «the answer holds no JSON object», і після трьох запитів юніт відкладається, хоча наглядач щоразу відповів чинним JSON-ом. У пісочниці 044 так відкладено юніт 1 (три відповіді PASS / BLOCK #4 / PASS, жодної не записано). Підагент без викликів інструментів відповідає текстом, і тоді поле заповнене — тому вада не проявляється в простих тестах. Докази: tasks/done/044-simplifier-live-check/report.md і тека evidence/ поруч.

Перевірити ті самі місця: усе, що читає last_assistant_message підагента (critic-и, business-analyst, simplifier — якщо для них є hook-и запису).
