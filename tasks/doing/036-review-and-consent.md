## Рішення власника
Одна форма згоди для всього: моя відповідь — рівно одне слово «так» (регістр і розділові знаки не важать). Усе інше, зокрема «так, але…», — вказівка агентові; нічого не застосовується.

## Що зробити
1. Єдине правило згоди — для застосування налаштувань, для піднесення уроку до правила і для закриття ескалації воріт. Питання воріт переформулювати: «Закрити ескалацію?» — відповідь «так». Оновити шаблони питань, механізм виконавця, tasks/README.md і docs/OWNER-GUIDE.md.
2. Команда огляду перейменовується з /review на /owner-review: у Claude Code вже є вбудована /review. Оновити всі згадки.
3. В огляді, у «Стані зараз», — вартість спроби, що триває, наскільки її видно з файлів стану.
4. В огляді — з кожної пропозиції правила посилання на відповідне питання в blocked/.
Детерміновані тести.
