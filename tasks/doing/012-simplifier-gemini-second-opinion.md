# 012 — Друга думка від Gemini для спрощувача (спершу проєкт)

Залежить від: 010
Аудит потрібен: ні

## Рішення власника
Добре мати погляд зовсім іншої моделі. Gemini не працює всередині Claude Code як модель, але може дати незалежну оцінку через окремий скрипт.

## Що зробити
Лише проєкт рішення, без будівництва:
- як скрипт надсилає знахідки спрощувача й diff у Gemini через API і записує згоду чи незгоду по кожній знахідці;
- де береться ключ доступу (на сервері, без запису в репозиторій);
- що робити, коли моделі не згодні;
- як виміряти, чи друга думка зменшує частку хибних видалень, і скільки це коштує.
Питання до власника — у розділ нижче, задачу — в blocked/.

## Готово, коли
Проєкт рішення в done/, питання поставлено.
