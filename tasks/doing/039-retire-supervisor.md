# 039 — Прибрати supervisor.sh: автономна робота лише через дошку

Залежить від: 035
Аудит потрібен: ні

## Рішення власника
Автономна робота йде лише через дошку. Старий спосіб — supervisor.sh, що вів роботу за графом фічі, — прибираємо: два способи робити одне й те саме — зайва складність. Це скасовує давніше рішення ставити його в кожен проєкт.

## Що зробити
1. Знайти все, чим користується лише supervisor.sh (скрипти й файли в .claude/unattended/, службовий unit для systemd, тести, сценарії золотого набору, документація), і прибрати. Усе спільне з дошкою — лишити.
2. Граф фічі, яким користується /feature-architect для планування, не чіпати: прибирається лише старий спосіб виконання.
3. Карта власності: прибрані файли двигуна позначити вилученими, щоб engine.py update прибирав їх у встановлених проєктах, не чіпаючи файлів проєкту.
4. Оновити документацію: автономна робота — дошка і board-runner.sh.
5. Новий еталон золотого набору. У звіті — що прибрано і скільки рядків.

## Готово, коли
Тести зелені; новий еталон; жодних посилань на supervisor.sh у робочих файлах.
