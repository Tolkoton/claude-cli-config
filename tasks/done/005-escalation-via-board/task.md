# 005 — Закриття ескалації воріт через дошку

Залежить від: дошка задач
Аудит потрібен: ні

## Що зробити
Зараз ескалацію воріт (після N блоків поспіль) власник мусить закривати командою в терміналі сервера. Власник терміналом сервера не користується.
- Коли ворота відкладають питання після N блоків, воно автоматично стає задачею в tasks/blocked/ з питанням до власника і варіантами відповіді.
- Відповідь «закрити» у файлі задачі закриває ескалацію. Команду gate.py --close-escalation запускає виконавець board-runner.sh, а не агент.
- Детерміновані тести.

## Готово, коли
Тести зелені; у звіті демонстрація: ескалація → задача в blocked/ → відповідь → закрито.
