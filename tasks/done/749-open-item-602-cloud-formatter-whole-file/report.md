## Наслідки, про які варто знати
- У двигуні `jq` більше не переформатовує `.json` після Edit/Write — і на сервері теж. Скриптів, що пишуть JSON самі,
  це не стосується.
- Для `.py` у двигуні після правки немає й швидкого lint-у `ruff check`. Так було й раніше, бо `py` входить у
  `CODE_EXTENSIONS` двигуна і `FORMAT_CMD="true"` уже тоді вважався власним formatter-ом проєкту. Lint лишається в Stop
  gate.
- Для форматування в двигуні крок 0 нічного prompt-а (перейменувати `ruff`/`black` на `.off`, вимкнути `prettier`)
  більше не потрібен. Чи прибирати його з prompt-а — вирішуєте ви. Що ще він зачіпає, я не перевіряв.

## Рішення, які я ухвалив сам
