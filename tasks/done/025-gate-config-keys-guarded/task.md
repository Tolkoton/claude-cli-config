## Рішення власника
Відома діра: зміною PROJECT_MARKER або CODE_EXTENSIONS у .claude/project.env хід обходить лінтер, типи й тести. Інші ключі налаштувань воріт уже під охороною — ці два теж мають бути.

## Що зробити
- Зміна PROJECT_MARKER або CODE_EXTENSIONS у diff ходу — блок воріт, так само як для інших охоронюваних ключів. Пройти можна лише тоді, коли контракт зрізу прямо дозволяє цю зміну.
- Детерміновані тести і сценарії золотого набору: зміна кожного ключа блокується; дозволена контрактом — проходить.

## Готово, коли
Тести зелені; золотий набір тотожний еталону, крім нових сценаріїв.
