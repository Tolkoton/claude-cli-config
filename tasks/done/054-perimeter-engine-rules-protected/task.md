## Що зробити
.engine/rules.md іде в always-loaded context кожної розмови, тобто впливає на все, що робить агент. Зараз агент може змінити його звичайним Edit/Write або shell-командою; видно це лише в diff. Правило стає правилом тільки з «так» власника — і запис у цей файл має бути можливим лише тим самим шляхом.
- protect-paths і block-dangerous не пускають прямий запис у .engine/rules.md ні через Edit/Write, ні через shell. Законний шлях — лише механізм піднесення уроку до правила після «так» власника.
- Тести на кожну форму запису, включно з негативними випадками (читання, git diff, grep мають проходити); golden set.

## Готово, коли
