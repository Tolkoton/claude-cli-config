## Що зроблено
- **Новий `.claude/hooks/shell_text.py`.** Перед усіма перевірками прибирає з команди те, що є лише текстом. Сам нічого не дозволяє: лише прибирає текст або повертає команду без змін.
- **`block-dangerous.sh`** судить результат (`$JUDGED`) у всіх місцях: `DANGEROUS_PATTERNS`, змінна власника, push, `shell_paths.py`, `shell_readonly.py`, commit policy. Самі перевірки не змінено. У тексті відмови лишається команда, як її набрано.
- **Текст прибирається лише коли виконано всі три умови:**
  1. Відома позиція відомої команди: аргументи `echo` і `printf`; `-m` у `git commit`, `git tag`, `git stash`; тіло heredoc для `cat` без аргументів і для `git commit`; шаблон `grep`; скрипт `sed`, якщо це лише `s/…/…/` без прапорців `e` і `w`; `--title`, `--what`, `--question`, `--do` у `board.py open-item`.
  2. Без підстановок: `'…'`, або `"…"` без `$`, зворотних лапок і `\`; heredoc із delimiter у лапках. Один виняток — ідіома `git commit -m "$(cat <<'EOF' … EOF)"`.
  3. У всьому виклику Bash нічого не може цей текст виконати: кожна проста команда — з короткого списку пасивних. Один `bash`, `sh`, `eval`, `python3 -c`, `xargs`, `source`, скрипт, `$(…)`, subshell, `if`/`for`, присвоєння чи змінна в позиції команди — і не прибирається нічого.
- **Запасний шлях.** Без `python3`, без скрипта, при його збої чи порожньому виводі судиться сира команда, як до 738.
- **Документи:** `docs/engine-limits.md` (розділ «Hooks guard tool calls, not scripts»), `.claude/references/hooks.md`, docstring `shell_paths.py`, `evals/README.md`, `docs/working-on-the-engine.md`.

## Чого це не ловить
- Текст, записаний у файл однією командою і виконаний **наступною**. Так було й до 738: Write і Edit дають те саме.
- Команда з чимось поза списком пасивних судиться ціла, тож зайві відмови там лишились. Приклад: `git commit -m '…' && git push`, або commit message із `$` чи `\"`. Обхід той самий: текст у файл через Write.

## Знайдено по дорозі — стара діра, не від 738
`bash -c 'rm <settings file>'`, `sh -c "cp … <inbox>"`, `eval 'cp …'` проходять повз `shell_paths.py`, коли після `-c` стоїть одна команда без роздільника. Перевірено на hooks до моєї зміни: так було й раніше. Набори 714, 054 і 056 цієї форми не мають. У 738 я її не чіпав — це зміна perimeter поза схваленим diff. Задача **600**.
