# 045 — Прибирання, коли дошка вільна

Залежить від: —
Аудит потрібен: ні

## Рішення власника
Одна дошка для всього, без cron. Вільний час виконавця йде на боротьбу зі складністю.

## Що зробити
- Коли виконавцеві нема чого брати (todo/ порожня, або все, що лишилося, чекає власника чи його присутності), він сам кладе на дошку задачу прибирання — не частіше ніж раз на добу.
- Задача прибирання запускає нічний режим спрощувача (python3 .claude/hooks/simplifier.py nightly) і діє за його правилами: безпечне — застосовує, решту — у звіт для огляду власника.
- Подія записується в журнал аномалій і видна в огляді.
- Детерміновані тести на підробленому claude.

## Готово, коли
Тести зелені; у звіті демонстрація: дошка вільна → з'явилася задача прибирання → виконано.
