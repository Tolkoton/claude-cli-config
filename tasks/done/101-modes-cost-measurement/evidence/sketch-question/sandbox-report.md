# Звіт: 010 — Поділ суми на рівні частини

## Що змінилось для власника
Відповідь на питання задачі — **так**: суму можна поділити на `parts` частин із точністю до цента так, щоб сума частин точно дорівнювала `amount`, частини відрізнялися щонайбільше на цент, а більші йшли першими. Робочий код не змінено: `refproj.pricing` лишився як був, функції `split_evenly` у ньому немає. Є запис ескізу `.engine/sketches/split-evenly.md` (reader: PASS) і код ескізу в `sketches/split-evenly/`.

Одне уточнення до «завжди»: воно справджується для сум у цілих центах. Суму з частками цента (10.005) неможливо скласти з частин у цілих центах, тож ескіз на неї дає `ValueError`. Задача про такі суми не каже нічого — це треба вирішити, коли функцію будуватимуть.

$ PYTHONPATH=src uv run --offline python sketches/split-evenly/check.py

Перевірені суми: кожен цент від 0.00 до 20.00, а також 999999999999.99, `Decimal("1E+3")` і `Decimal("7")`, кожна на 1..40 частин. Це перебір, не доказ для всіх сум; спосіб (цілі центи, `divmod`, зайві центи першим частинам) округлення не містить.
