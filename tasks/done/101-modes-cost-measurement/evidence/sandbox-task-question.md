# 010 — Поділ суми на рівні частини

Залежить від: —
Потрібна присутність власника: ні
Режим: ескіз
Аудит потрібен: ні

## Що зробити
- Питання, на яке потрібна відповідь: чи можна в `refproj.pricing` поділити суму на `parts` частин із точністю до цента так, щоб сума частин завжди точно дорівнювала `amount`, частини відрізнялися щонайбільше на один цент, а більші йшли першими — функцією `split_evenly(amount: Decimal, parts: int) -> list[Decimal]`?
- `parts` менше одного або `amount` менше нуля мають давати `ValueError`.

## Готово, коли
- Є відповідь «так», «ні» або «не з'ясовано» з виводом, який її доводить: 10.00 на 3 дає 3.34, 3.33, 3.33; сума частин дорівнює `amount` на всіх перевірених вхідних даних; обидві відмови перевірено.
