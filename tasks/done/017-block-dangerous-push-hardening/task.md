# 017 — Посилити block-dangerous для push

Залежить від: 016
Потрібна присутність власника: так
Аудит потрібен: ні

## Рішення власника
Push лишається під запитом. Але гак має сам надійно зупиняти небезпечні форми — незалежно від запиту.

## Що зробити
У .claude/hooks/block-dangerous.sh, з тестом на кожну форму:
- впізнавати push у будь-якому написанні: git -C <тека> push, git -c ключ=значення push, кілька пробілів між словами;
- force push з прапорцем у будь-якому місці до роздільника: --force, -f, злиті короткі прапорці на кшталт -uf, --force-with-lease, --force-if-includes, а також refspec із плюсом (+гілка) і --mirror;
- push у main або stable за будь-яким refspec, включно з HEAD:main;
- видалення віддалених гілок: --delete, -d, refspec із двокрапкою на початку (:гілка).
Правило ask для push не змінювати. Золотий набір — нові сценарії для кожної форми.

## Готово, коли
Тести зелені; золотий набір тотожний, крім нових сценаріїв.
