# 001 — Критики знову на найсильнішій моделі

Залежить від: —
Аудит потрібен: ні

## Рішення власника
Критики працюють на найсильнішій моделі. Дешевша модель для критиків — шлях у нікуди. Межа в два раунди критика лишається.

## Що зробити
- Пакет витрат поставив `model: sonnet` у critic-core, feature-critic, master-critic і slice-planner-critic. Прибрати це поле, щоб критики успадковували модель головної сесії.
- Перевірити, що жоден інший агент двигуна не має дешевшої моделі.
- Детермінований тест: жоден критик не має моделі, слабшої за модель головної сесії.

## Готово, коли
Тест зелений, золотий набір тотожний, у звіті перелік змінених файлів.
