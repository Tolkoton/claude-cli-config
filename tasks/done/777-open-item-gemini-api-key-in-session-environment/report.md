  Про це лежить окреме питання з трьома варіантами: `tasks/blocked/1734-open-item-gemini-api-key-in-runner-parent-processe.md`.

## Демонстрація на хвилину
У сесії, яку стартував runner (друкуються лише назви й лічильники, значення — ніде):

```bash
[ -n "${GEMINI_API_KEY+x}" ] && echo SET || echo unset          # unset
env | cut -d= -f1 | grep -i -E 'gemini|google'                  # нічого
```

Те, що лишилось, — скільки разів назва `GEMINI_API_KEY` трапляється в середовищі кожного процесу від сесії вгору
(`tr '\0' '\n' < /proc/<pid>/environ | cut -d= -f1 | grep -c -x GEMINI_API_KEY`):

| процес | назва в середовищі |
|---|---|
| `bash` (оболонка інструмента агента) | 0 |
| `claude -p …` (сесія агента) | 0 |
| `bash .claude/unattended/board-runner.sh` | 0 |
| `bash -c cd /home/lao/engine && export PATH=… && unset …` | 1 |
| `tmux new -d -s engine-board …` (tmux server) | 1 |

```bash
tmux show-environment -g | cut -d= -f1 | grep -i gemini         # GEMINI_API_KEY
```
