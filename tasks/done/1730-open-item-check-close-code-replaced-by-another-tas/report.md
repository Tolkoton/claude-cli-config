## Рішення, які я ухвалив сам
- **Пункт (3) задачі прочитано так:** «файл після PASS змінено ще раз» — це зміна самою задачею. Пізніша зміна третьою
  задачею commit не «розкриває». Інакше умова задачі («752 зелена без нового audit-у») не виконується: після PASS 752
  файли `overseer_verdict.py` і `tests/test_overseer_fresh.py` міняли ще три задачі (762, 111, 112).
- **Умову «чужий commit був в історії запиту PASS» додав понад текст задачі.** Без неї PASS, що бачив той самий вміст
  ще до commit-а задачі (інша задача повернула файл до старого стану), покрив би commit, якого не бачив.
- **Обхід пізніших commit-ів файла зупиняється на першому commit-і самої задачі.** Так нове правило не зачіпає
  випадків задачі 754 (тест «виправлення змінено після PASS — не покрито жоден» лишився зеленим).
- **Розвилку про PASS «-» не поставив питанням у цю задачу, а поклав пропозицією:** задача зроблена за своїм текстом,
  overseer дав PASS, а звуження правила — окрема зміна.
