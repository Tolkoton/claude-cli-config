# 089 — Architecture overview двигуна: звіт

## Що змінилось для власника
- Є `docs/ARCHITECTURE.md` — карта двигуна простою мовою, з англійськими технічними термінами: ролі
  (де кожна визначена і що робить), чотири рівні проєктування, task board і runner, hooks і gates,
  пам'ять і уроки, perimeter, встановлення й реліз. Кожне твердження посилається на файл, де деталі.
- Три діаграми Mermaid: шлях однієї задачі (хто кладе задачу; `todo/` → `doing/` → `done/` або
  `blocked/`; що runner робить сам на ваше «так»; задачі «з присутнім власником»); шлях одного slice
  (скелет, test manager у точці (a), tester або builder, overseer по кожному юніту, точка (b)); які
  hooks на які події спрацьовують — з matcher-ами дослівно з налаштувань.
- Новий тест `tests/test_architecture_doc.py` (у швидкому наборі, 0.05 с): кожен шлях у зворотних
  лапках існує; три діаграми на місці; діаграма hooks збігається з `.claude/settings.json` в обидва
  боки — кожен прописаний hook стоїть у своїй події після свого matcher-а, і кожен намальований
  hook справді прописаний. Перейменували файл, додали, прибрали чи звузили hook і не виправили карту
  — тест червоний.
- `docs/working-on-the-engine.md` має рядок про цей документ.
