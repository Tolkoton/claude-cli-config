# 706 — Вердикт наглядача не записувався: звіт

## Що змінилось для власника
Вердикт наглядача тепер записується. Раніше наглядач відповідав чинним вердиктом, а в журнал нічого не потрапляло, і після трьох запитів юніт відкладався до вас (так було в 076, 045 і в пісочниці 044). Причина одна, спільна із задачею 705, і її виправлено.

Наглядач завжди викликає інструменти перед відповіддю, а тоді Claude Code 2.1.289 передає його відповідь через виклик `SubagentHandback`, а не в полі `last_assistant_message`. Hook запису читав лише це поле. Тепер, коли поле порожнє, він бере відповідь з останнього виклику `SubagentHandback` у транскрипті підагента (`agent_transcript_path`). `.claude/settings.json` міняти не довелося.

Виправлення перевірено наживо: наглядач цієї ж задачі викликав 12 інструментів, відповів через `SubagentHandback`, і вердикт PASS записано з першого запиту.

## Демонстрація на хвилину
```bash
python3 tests/test_overseer_fresh.py | tail -8      # п'ять нових перевірок, усі ok
python3 .claude/hooks/overseer_verdict.py status    # останній вердикт: PASS 20261006T024303Z-69c5aa
python3 .claude/hooks/bugfix.py prove --record .engine/bugs/001-verdict-handback.md --test tests/test_overseer_fresh.py \
  --cmd "python3 tests/test_overseer_fresh.py" --expect "FAIL a verdict handed back by SubagentHandback is recorded"
```
Остання команда має надрукувати `PROVED: tests/test_overseer_fresh.py fails on 5b4156d and passes on the working tree`.
