## Рішення, які я ухвалив сам
- **Другої такої самої перевірки не дописував.** Задача каже «дописати перевірку», але вона вже є, названа номером
  цієї задачі й червоніє саме на описаній ваді. Це моє тлумачення: задача — закрити test gap, а не додати рядок.

  вердикту, у git не лишилось (739 — один commit), тому форма mutant-а — моя реконструкція з тексту вердикту
  («keeps both lines, because they differ by date»).
