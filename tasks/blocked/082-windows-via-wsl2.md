# 082 — Windows через WSL2

Залежить від: —

## Рішення власника
Двигун підтримує Windows через WSL2: усередині WSL2 (Ubuntu) він працює як на звичайному Linux. Нативну Windows (Git Bash, PowerShell) не будуємо. Налаштувати WSL2 може будь-який інженер.

## Що зробити
- docs/WINDOWS.md: покроково, людською мовою — wsl --install, Ubuntu, Python, uv, jq, git, Claude Code усередині WSL2, встановлення двигуна; як працювати з VS Code через WSL.
- env-check розпізнає WSL і попереджає про типові пастки: проєкт на диску Windows (/mnt/c/...) — повільно і плутаються права; git, що міняє закінчення рядків (core.autocrlf), — порадити input.
- Розділ «Windows» в docs/OWNER-GUIDE.md і згадка в README.
- Детерміновані тести env-check на підроблених ознаках WSL (вміст /proc/version, шлях проєкту).
- Документ цілей двигуна (.engine/goals.md) не чіпати: його зміна — лише з «так» власника. Якщо там є пункт «Windows — поки що ні», підготуй пропозицію зміни і питання до власника в blocked/.
