# Класи задач

Номер задачі — це клас × 100 + порядковий номер задачі в класі: 301 — перша задача класу 3,
310 — десята. Номер новій задачі дає task board: наступний після найбільшого в класі.

- **Порядок рядків таблиці — це порядок, у якому runner бере класи.** Щоб змінити пріоритет,
  переставте рядки. Усередині класу першою йде задача з меншим номером; задачі, на які ви щойно
  відповіли (`tasks/.first`), ідуть першими в будь-якому разі.
- **Коли в класі скінчились номери 01–99, він продовжується** в сотні, більшій на тисячу: клас 7
  після 799 іде в 1701–1799, далі 2701… Остання цифра сотень — завжди клас.
- **Клас задачі** — необов'язковий рядок `Клас: <номер>` під її назвою. Файл без номера в inbox
  (`назва.md`) з таким рядком отримує наступний номер свого класу.
- Рядок таблиці починається з `|` на початку рядка, у першій клітинці — номер класу від 0 до 9.
  Клітинку «Продовження» читає лише людина.
