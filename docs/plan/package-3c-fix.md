ДЕФЕКТ (знайшов власник під час перевірки)
engine.py переносить дані проєкту, але не стан машини. У проєкті на v0.10.1 стан лежить у старих місцях:
- .claude/overseer/: mode, .last_audit_sha, .last_continue_sha, .continue_count, .budget-*.json, complexity-report.md;
- .claude/unattended/: state.json, cost.json, heartbeat, restarts.log, sim-plan.txt, supervisor.lock, logs/, archive/.
Нова карта через правило «engine .claude/**» вважає їх файлами двигуна, тому оновлення:
- видаляє як «retired by the engine» ті, чий вміст збігся з історією двигуна (так зник mode=unattended);
- назавжди утримує як «edited» решту (.last_audit_sha), і кожне оновлення закінчується з кодом 1;
- новий блок .gitignore старих шляхів уже не ігнорує.
Як відтворити: install --ref v0.10.1 у порожній репозиторій; записати mode=unattended і .last_audit_sha; update --ref HEAD.
