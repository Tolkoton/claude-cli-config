   - Хмарна сесія: commit у робочу гілку сесії. Підготуй спосіб розпізнати хмарне середовище і скрипт-зонд, який друкує факти про середовище. Перемикач для хмари лиши вимкненим, доки я не прожену зонд у справжній хмарній сесії.
