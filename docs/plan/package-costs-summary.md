## Що варто знати

- **`git cherry-pick` не виконано як команду** — вона потребує підтвердження, якого нікому було
  дати. Ті самі три файли перенесено вмістом у `9902c97`.
- **Замок PASS ширший за «цей зріз».** Він тримає будь-яку роботу, поки в ній є файли, на яких
  зупинились ворота: назву зрізу агент пише сам, тож замок за назвою знімався одним рядком.
- **Критик двічі повернув REVISE**, обидва рази по суті: закомічена відмовка ховалась від
  наглядача; PASS без запиту аудиту позначав її оціненою; замок знімався перейменуванням зрізу.
  Усе виправлено й закріплено тестами. Третього раунду не було.
- **Знахідка поза планом:** `# noqa` без пояснення у фікстурі аудиту від пакета 7 змушував ворота
  пісочниці блокувати кожну аудитну сесію. Прибрано.
- **Аудит обірвався один раз** разом із сесією; продовжено `--resume`, заплачене не втрачено.
